## 1. Введение

В задачах научных и инженерных вычислений часто встречаются разреженные матрицы, в которых большинство элементов равны нулю. Использование плотных форматов хранения в таких случаях неэффективно как по памяти, так и по времени вычислений. Для решения этой проблемы применяются специальные форматы хранения разреженных матриц.

В данной работе рассматривается задача умножения разреженных матриц с элементами типа `double`, представленных в формате CCS (Compressed Column Storage). Реализованы последовательная и параллельная версии алгоритма. Основная цель работы — реализовать корректное умножение разреженных матриц и проанализировать влияние распараллеливания по MPI на производительность.

---

## 2. Постановка задачи

Требуется реализовать умножение двух разреженных матриц  
` C = A * B `.

Входные данные представляют собой две матрицы в формате CCS. Формат CCS хранит матрицу по столбцам: для каждого столбца задаётся диапазон ненулевых элементов, их индексы строк и значения. Все элементы матриц имеют тип `double`. Размеры матриц должны быть согласованы для операции умножения.

Результатом работы является матрица \( C \), также представленная в формате CCS. Реализация должна корректно работать как в последовательном режиме, так и в параллельном режиме при любом количестве MPI-процессов, начиная с одного.

---

## 3. Последовательный алгоритм

Последовательная версия реализует классический алгоритм умножения разреженных матриц, адаптированный под формат CCS. Основной обход выполняется по столбцам матрицы \( B \).

Для каждого столбца \( j \) матрицы \( B \) перебираются все ненулевые элементы \( B(k, j) \). Для каждого такого элемента просматривается соответствующий столбец \( k \) матрицы \( A \). Все ненулевые элементы \( A(i, k) \) дают вклад \( A(i, k) \cdot B(k, j) \) в результирующий столбец \( C(:, j) \).

Для накопления промежуточных значений используется временный аккумулятор по строкам и список затронутых строк. Это позволяет эффективно очищать данные при переходе к следующему столбцу, не обнуляя весь массив. После завершения обработки столбца строки сортируются, значения, близкие к нулю, отбрасываются, и формируется очередной столбец результирующей матрицы в формате CCS.

---

## 4. Схема параллелизации

Параллельная версия реализована с использованием MPI и основана на распараллеливании по столбцам матрицы `B`, а значит и по столбцам результирующей матрицы `C`. Такой подход хорошо подходит для формата CCS, поскольку столбцы результата вычисляются независимо.

В начале работы матрицы `A`  и `B` рассылаются всем процессам с помощью `MPI_Bcast`. После этого диапазон столбцов матрицы `B` равномерно распределяется между процессами. Каждый процесс вычисляет только свой набор столбцов результирующей матрицы, используя тот же алгоритм, что и в последовательной версии.

После завершения локальных вычислений частичные результаты собираются на процессе с рангом 0 с использованием коллективных операций `MPI_Gather` и `MPI_Gatherv`. На корневом процессе формируется итоговая матрица `C` в формате CCS, после чего она рассылается всем процессам с помощью `MPI_Bcast`.

---

## 5. Детали реализации

Проект разделён на последовательную и параллельную части. Последовательная версия используется как базовая реализация и как эталон для проверки корректности MPI-версии. Параллельная версия повторяет логику последовательного алгоритма, но выполняет вычисления только для выделенного диапазона столбцов.

Особое внимание уделено корректному формированию структуры CCS: массив `col_ptr` монотонно возрастает, индексы строк внутри столбцов отсортированы, а значения, близкие к нулю, отбрасываются. Для проверки корректности используется контрольная сумма результирующей матрицы.

Корректность реализации проверялась сравнением результатов последовательной и параллельной версий. Все функциональные и производительные тесты были успешно пройдены.

В работе реализовано умножение разреженных матриц в формате CCS в последовательном и параллельном вариантах. Последовательная версия служит базовой реализацией, а MPI-версия использует распараллеливание по столбцам матрицы.
